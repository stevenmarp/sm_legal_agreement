# SM Legal Agreement - Dynamic Document Template Builder

Beautiful, flexible document template builder for Odoo 18.0

Create dynamic document templates with placeholders that can be mapped to any Odoo model fields or free text values.

## Features

- ✅ Create unlimited document templates with HTML editor
- ✅ Use dynamic placeholders like {{1}}, {{2}}, {{3}}...
- ✅ Map placeholders to any field from any Odoo model
- ✅ Or use free text values for static content
- ✅ Live preview with demo values
- ✅ Generate PDF reports from templates
- ✅ Multi-company support
- ✅ Easy to use interface

## Installation

1. Download the module from Odoo Apps Store
2. Extract to your Odoo addons directory
3. Restart Odoo server
4. Go to Apps → Update Apps List
5. Search for "Dynamic Document Template Builder"
6. Click Install
