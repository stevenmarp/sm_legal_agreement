Dynamic Document Template Builder

Create powerful document templates with dynamic placeholders

  • ✅ Create unlimited document templates with rich HTML editor
  • ✅ Use dynamic placeholders like {{1}}, {{2}}, {{3}}...
  • ✅ Map placeholders to any field from any Odoo model
  • ✅ Or use free text values for static content
  • ✅ Live preview with demo values
  • ✅ Multi-company support
  • ✅ Easy to use, no coding required

How It Works

Step 1: Create Your Template

Write your document content using {{1}}, {{2}}, etc. as placeholders for dynamic content.

Dear {{1}},

This agreement is made between {{2}} (the "Company") and {{1}} (the "Client") 
on {{3}}.

The total amount payable is {{4}}.

Best regards,
{{5}}

Step 2: Configure Variables

For each placeholder, choose how to fill it:

Placeholder Type Value/Field
{{1}} Model Field partner_id.name
{{2}} Free Text ABC Corporation Ltd.
{{3}} Model Field date_order
{{4}} Model Field amount_total
{{5}} Free Text John Smith, CEO

Step 3: Generate Documents

Use the template with any record from your selected model to automatically generate the document!
