Key Features

1 Dynamic Placeholders

Use dynamic placeholders like {{1}}, {{2}}, {{3}}... in your document templates. Map each placeholder to any field from any Odoo model, or use free text values for static content. Unlimited variables per template.

2 Model Field Mapping

Map placeholders to any field from any Odoo model using the dynamic field selector. Supports relational fields (e.g., partner_id.name, order_line.product_id.name). The field selector provides an intuitive UI to browse and pick fields.

3 Live Preview

Preview your document templates with demo values before generating the final document. See exactly how your template will look with real-time placeholder replacement.

4 PDF Report Generation

Generate professional PDF reports from your templates with a single click. The generated documents include all dynamic content properly filled in from the linked records.

5 Multi-Company Support

Create separate document templates for each company. Full multi-company support with proper security rules to keep templates isolated per company.

6 No Coding Required

Everything is done through the Odoo UI — no technical knowledge needed. Create templates, configure variables, and generate documents all from the web interface.

How It Works

Step 1: Create a new template and write your document using {{1}}, {{2}}, etc. for dynamic parts.

Dear {{1}},

This agreement is made between {{2}} (the "Company") and {{1}} (the "Client") on {{3}}.
The total amount payable is {{4}}.

Best regards,
{{5}}

Step 2: Configure each variable — pick "Model Field" to link to a model field, or "Free Text" for static values.

Step 3: Use the template with any record to automatically generate the document!
